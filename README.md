# 电商用户行为分析（阿里天池 UserBehavior 数据集）

基于阿里天池公开的淘宝用户行为数据集（100万+条记录），使用 MySQL 完成数据清洗与深度分析，Power BI 搭建交互式仪表盘，定位用户转化瓶颈并提出运营策略建议。

## 项目背景

电商平台普遍面临两个核心问题：
1. **用户转化路径长**：从浏览到下单，中间流失严重，但缺乏量化分析
2. **高价值用户识别难**：无法区分谁是真正贡献利润的核心用户

本项目基于真实电商行为数据，构建从数据获取、清洗、分析到可视化的完整链路，为运营策略提供数据支持。

## 技术栈

| 工具 | 用途 |

| MySQL | 数据导入、清洗、多表关联、窗口函数分析 |
| Power BI | 数据建模、DAX 度量值、交互式仪表盘 |

## 数据来源

阿里天池公开数据集 **UserBehavior**（淘宝用户行为数据）

- 数据集地址：https://tianchi.aliyun.com/dataset/649
- 时间范围：2017-11-25 至 2017-12-03
- 记录数：100,150,807 条
- 用户数：987,994
- 商品数：4,162,024
- 类目数：9,439
- 字段说明：

| 字段 | 类型 | 说明 |
|------|------|------|
| user_id | 整数 | 序列化后的用户 ID |
| item_id | 整数 | 序列化后的商品 ID |
| category_id | 整数 | 商品所属类目 ID |
| behavior_type | 字符串 | pv(浏览)、fav(收藏)、cart(加购)、buy(购买) |
| timestamp | 整数 | 行为发生的 Unix 时间戳（秒级） |

> 原始数据文件约 3.4GB，请从上方天池链接自行下载。下载后解压得到 `UserBehavior.csv`，按 `sql/01_create_table.sql` 中的说明导入 MySQL。

## 分析模块

### 1. 整体经营概览
统计平台总用户数、总商品数、总类目数，以及浏览、收藏、加购、购买四类行为的次数分布。

### 2. 用户行为转化漏斗
构建「浏览 → 收藏 → 加购 → 购买」的用户级转化漏斗，计算各环节转化率，定位主要流失环节。

### 3. RFM 用户价值分层
使用 `NTILE(4)` 窗口函数对用户的最近购买时间（R）、购买频率（F）、购买次数（M）进行独立评分，划分：
- 高价值用户
- 新客 / 潜力用户
- 流失预警用户
- 一般 / 流失用户

### 4. 用户留存分析
基于用户首次活跃日期，计算次日留存率与 7 日留存率，评估用户粘性。

### 5. 商品与品类分析
- 购买次数 TOP10 商品排名
- 品类购买占比分布

### 6. 时间维度分析
- 24 小时用户活跃趋势与购买转化率
- 每日活跃用户趋势

## 核心发现

- 用户活跃高峰集中在 **20:00-22:00**，该时段行为量最大
- 「加购 → 购买」环节转化率仅约 **91.34%**，是主要流失环节
- 高价值用户占比约 **19.90%**，贡献了平台大部分购买行为
- 次日留存率约 **70.34%**，7 日留存率约 **90.72%**

## 解决方案
针对项目背景提出的两大业务问题，通过数据分析手段逐一解决：

1. **用户转化路径长，浏览到下单流失严重，缺乏量化分析**
采用用户行为漏斗分析，利用SQL统计浏览、收藏、加购、购买四个环节的用户数量，计算各环节转化率与流失率，量化每个步骤的用户损耗；
在PowerBI绘制转化漏斗图，直观定位流失最严重的节点。根据流失环节给出运营建议：若浏览到收藏流失较高，则优化商品详情页、突出商品卖点；
若加购到购买流失突出，可以发放优惠券、推送未下单提醒，减少购物车弃购。

2. **高价值用户识别难，无法区分核心贡献用户**
使用RFM模型完成用户分层。通过SQL计算R（最近购买时间）、F（购买频次），由于本数据集缺少金额字段，使用购买行为次数替代M指标；
依据RFM打分，将用户划分为高价值用户、新用户、流失预警用户、一般用户等群体。在PowerBI制作环形图，直观查看各分层用户占比，制定差异化运营策略：对高价值用户重点维护，提供专属活动；
对流失预警用户推送优惠进行召回；对新用户做好引导，促进首单成交。

除此之外，配套开展多维度辅助分析：通过24小时用户时段行为分析，锁定用户活跃高峰，选择高峰时段投放营销活动；
通过TOP商品分析挖掘爆款商品，依托爆款引流提升整体下单量；通过用户留存分析，评估新用户粘性，从源头降低用户流失。

## 如何运行

1. 从阿里天池下载 UserBehavior 数据集：https://tianchi.aliyun.com/dataset/649
2. 在 MySQL 中依次执行 `sql/` 目录下的脚本（按编号顺序）
3. 用 Power BI Desktop 打开 `powerbi/ecommerce_dashboard.pbix`
4. 如需重新连接数据源，在 Power BI 中「转换数据 → 数据源设置」修改 MySQL 连接信息

## 环境要求

- MySQL 8.0+
- Power BI Desktop（2023 年及以后版本）
- 建议内存 8GB 以上（处理百万级数据）
